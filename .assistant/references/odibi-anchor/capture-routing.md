# Capture routing

Use the smallest durable record that matches what happened. Do not turn a finding into
authority or preserve routine noise as knowledge.

| What happened | Route | Do not substitute |
| --- | --- | --- |
| Bounded work is accepted | Task context | Durable finding or approval |
| Routine action or state transition | Automatic task journal | Observation or memory |
| Noteworthy factual finding | Observation | Decision or implementation instruction |
| Reproducible support for a claim | Evidence in the governing record | Interpretation alone |
| Material unresolved uncertainty | Problem | Predetermined feature request |
| Consequential settled choice | Decision | Chat history or code comment |
| Precise required behavior | Spec | General plan |
| Authorized bounded execution | Work Item | Idea or unresolved research |
| Reusable operational insight | Memory candidate | Raw event log |
| Repeated, validated insight | Lesson | One-off observation |
| Stable repeatable procedure | Trail | Broad skill |
| Broad durable method or knowledge | Skill/reference | Project-specific fact |
| Retained external material | Attributed source record | Bare URL or unattributed copy |
| Reproducible analysis/execution | Notebook | Canonical product source |
| Test, review, preflight, or gate result | Verification result | Invocation without decisive output |
| Point-in-time state must be frozen | Snapshot | Mutable summary |
| Another session/agent must continue | Handoff | Conversation history |
| Terminal outcome | Universal terminal return | Progress narrative |

If two routes apply, preserve one source and link outward: evidence supports a Problem,
Decision, Spec, or Work Item; an assessed observation may become a memory candidate; a
repeated lesson may justify a trail or proposed reference update. Never copy the same claim
into several records without lineage.

## Authority boundary

Observations, evidence, journals, and memories inform work. They do not approve source
changes, activate a Spec, authorize a Work Item, satisfy owner approval, or prove a check
passed. Missing authority remains the next authority required.
