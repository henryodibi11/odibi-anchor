# Cross-functional PR

## When to load
Load for explicit PR preparation, readiness, reviewer handoff, or a cross-functional evidence package. Use [the audience and evidence workflow](references/backbone.md).

## When NOT to load
Do not load for independent PR review; use the host's independent-review guidance instead. Do not load for routine self-checks, generic documentation, or work-item tracking.

## Workflow
State user impact and scope; explain contracts and risks in audience language; provide verification and operational evidence; identify security, data, docs, rollout, rollback, and ownership implications; make review questions explicit.

## Enforcement
Self-enforced. Global instructions apply. PR prose cannot substitute for review or gate evidence.
