# Incident response

## When to load
Load for an active outage, production impact, high-severity incident, or incident timeline. Follow [the response backbone](references/backbone.md).

## When NOT to load
Do not load for ordinary debugging or performance investigation without active incident conditions.

## Workflow
Declare impact, commander, and communication cadence; preserve evidence; contain with the smallest reversible action; verify recovery through user and system signals; monitor recurrence; build an observation-based timeline; separate root cause from contributing conditions and assign follow-ups.

## Enforcement
Self-enforced. Global instructions apply. Urgency does not grant destructive authority; evidence and approvals remain required.
