# Onboarding planning

Before ingestion, establish source ownership and provenance, expected grain and keys,
schema/format evidence, volume and refresh cadence, quality acceptance rules, idempotency,
downstream consumers, failure handling, and rollback. Resolve the highest-risk unknown with
the smallest read-only profile before selecting parsing or persistence behavior. This is the
onboarding application of the full preserved data planning workflow retained by the data
operations owner.
