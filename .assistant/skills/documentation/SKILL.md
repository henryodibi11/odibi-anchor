# Documentation

## When to load
Load for an explicit documentation deliverable or verified documentation drift. Follow [the audience and truth-source workflow](references/backbone.md).

## When NOT to load
Do not load for formal Specs, work-item records, or comments incidental to ordinary code changes.

## Workflow
Identify audience and task; derive claims from authoritative source and observed behavior; apply the task's runtime `capture_guidance` to retained claims and sources; lead with outcomes and prerequisites; include examples, failure modes, and operations where material; validate commands, links, terminology, and drift.

## Enforcement
Advisory. Global instructions apply. Documentation claims require evidence and do not override source authority.
