# Contributing

Thank you for contributing to Odibi Anchor.

1. Open an issue before substantial or behavior-changing work.
2. Fork the repository and create a focused branch from `main`.
3. Use Python 3.11 or newer and install development dependencies with `python -m pip install -e '.[dev,mcp]'`.
4. Add or update tests and documentation with the implementation.
5. Run `python -m pytest` and the relevant lint/type checks before opening a pull request.
6. Keep runtime state, credentials, generated manifests, databases, and private repository material out of commits.

By submitting a contribution, you agree that it is licensed under Apache-2.0 as described by [LICENSE](LICENSE). Contributions must be your own work or otherwise compatible with this license and properly attributed.

Please use public issues only for non-sensitive material. Do not post vulnerabilities, secrets, private source, or captured runtime state publicly.
