# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include
credentials, private source, runtime databases, managed-project records, or customer data
in a public issue.

Include the affected version, impact, minimal reproduction, and any known mitigation.
You should receive an initial response within seven days. Public disclosure should wait
until a fix or coordinated mitigation is available.

## Supported versions

Security fixes are provided for the latest published release.
